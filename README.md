# Grammar Express

Created by Avazbek Mirzaev. © 2026 Avazbek Mirzaev. All rights reserved.

English grammar for kids: 35 stations, all 12 tenses, a 600-word picture dictionary with a human voice, and 7 games.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `grammar-express`). Make it **Public**.
2. Click **Add file → Upload files**. Drag in all the files from this folder (there are no sub-folders). Click **Commit changes**.
3. Go to **Settings → Pages**. Under "Branch", choose `main` and `/ (root)`, then click **Save**.
4. After 1–2 minutes your app is live at `https://YOUR-USERNAME.github.io/grammar-express/`

## Put it on a phone's home screen
- **Android (Chrome):** open the link, tap ⋮ → **Add to Home screen**.
- **iPhone (Safari):** open the link, tap Share → **Add to Home Screen**.

Progress (stars, tickets, words) is saved on each device and browser separately.
